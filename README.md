# Nino Gás Landing Page — Vercel

Este projeto é uma página HTML estática pronta para deploy na Vercel.

## Como corrigir o 404

1. Garanta que o arquivo principal esteja na raiz do repositório com o nome `index.html`.
2. Faça commit e push para o GitHub.
3. Na Vercel, importe o repositório novamente ou clique em Redeploy.
4. Em Framework Preset, use `Other`.
5. Build Command: deixe vazio.
6. Output Directory: deixe vazio ou use `.`.

O arquivo original `ninogas-landing.html` foi renomeado para `index.html`, que é o arquivo padrão carregado na raiz do domínio.
